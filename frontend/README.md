# Frontend

React + TypeScript + Vite frontend for Memora.

## Current purpose

Provide the review-first UI for Memora V1.

## Included stack

- React 19.2.1
- TypeScript 6.0.2
- Vite 8.0.8
- TanStack Query 5.99.1
- React Hook Form 7.73.0
- Zod 4.3.6
- Tailwind CSS 4.2.2

## Local run

Prerequisites:

- Node.js installed
- npm available

Run:

```bash
cd frontend
npm install
npm run dev
```

Default URL:

- `http://localhost:5173`
