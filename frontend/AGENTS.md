# frontend/AGENTS.md

## Purpose

Frontend is the Memora review/search/edit UI.

## Responsibilities

- login screen
- Needs Review UI
- Failures UI
- Approved list UI
- category sidebar
- search/filter/sort controls
- item inspection/edit flow

## Rules

- keep frontend aligned with backend contracts
- prefer simple, readable components
- do not invent product behavior not backed by requirements
- default landing view must be Needs Review
