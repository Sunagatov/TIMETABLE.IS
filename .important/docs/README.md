# Lexora Requirements Pack

This directory is a replacement-oriented requirements pack for Lexora.

It is designed to help:

- Codex CLI
- Claude CLI

## Intent

These docs are intentionally more explicit than lightweight product notes.
They are meant to reduce ambiguity, reduce implementation questions, and reduce wasted AI tokens.
