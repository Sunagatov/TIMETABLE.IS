# Future Phases

## Likely future features

### Question workflow

Future versions may support:

- `QUESTION` item type
- automatic answer generation
- answer editing/rejection/regeneration
- optional web-backed answers

This functionality is intentionally removed from initial V1 MVP.

### Labels

Future versions may support:

- AI-suggested labels
- manual label editing

### Regeneration workflows

Future versions may allow:

- regenerate cleaned text
- regenerate category proposal
- preserve previous AI candidate versions

### New category proposals

Future versions may support AI-suggested new categories requiring human approval.

### Audio storage

Future versions may introduce Memora-managed audio storage to support:

- playback in web app
- audio download
- reliable audio reprocessing

### Semantic search

Future versions may add semantic / embedding-based retrieval.

### Multi-client growth

Because backend must remain client-agnostic, future clients may include:

- mobile app
- desktop app
- additional bot clients
