# AI Behavior Rules

## V1 allowed AI responsibilities

- clean and improve wording
- preserve original meaning
- assign initial type
- assign category path from existing categories only
- suggest priority if confidence is high

## V1 forbidden AI behavior

- invent new category paths for approval flow
- regenerate alternate drafts inside review UI
- split one Telegram message into multiple items
- reinterpret the user's intended meaning into a different corrected meaning
