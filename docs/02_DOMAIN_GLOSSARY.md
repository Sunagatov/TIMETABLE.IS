# Domain Glossary

- **Item**: a captured unit from one Telegram message
- **Raw input text**: original user text from Telegram text message
- **Raw transcript**: transcription result for voice input
- **Cleaned text**: AI-cleaned version that stays semantically close to the original
- **Approved item**: human-reviewed item accepted into the main knowledge base
- **Needs Review**: area for AI-processed but not yet human-approved items
- **Failures**: area for items that failed at some processing stage
- **Type**: IDEA / THOUGHT / REMINDER / OTHER
- **Category path**: category / subcategory / subsubcategory
