# Scope and MVP

## In scope for initial V1

- Single-user only
- Telegram text and voice input
- Async processing
- Web app login and session auth
- Needs Review page
- Failures page
- Approved items list
- Category tree with exactly 3 levels
- Manual category management (create, rename, reassign items, delete empty)
- Editing and approval workflow

## Out of scope for initial V1

- Multi-user support
- Public sharing
- Mobile app
- Labels
- Question-answering flow
- AI-generated new categories requiring approval
- Audio storage in Mindraft
- Audio replay/download in web app
- Advanced semantic search
- Regeneration flows
- View-count sorting
