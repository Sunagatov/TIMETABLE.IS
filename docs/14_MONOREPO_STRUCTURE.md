# Monorepo Structure

```text
mindraft/
  docs/
  backend/
  frontend/
  telegram-bot/
  scripts/
  compose.yaml
  .env.example
  README.md
```

## Intent

- `backend/` holds core APIs and processing orchestration
- `frontend/` holds the web UI
- `telegram-bot/` holds the Telegram adapter only
- `docs/` holds requirements and design guidance
