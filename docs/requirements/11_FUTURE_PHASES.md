# Future Phases

These are intentionally **not** initial V1 MVP features.

## Likely future additions

- `QUESTION` type and question-answering workflow
- answer editing/reject/regenerate flows
- labels
- semantic search
- AI-generated new category proposals needing human approval
- regeneration of AI outputs while preserving earlier candidates
- Memora-managed audio storage
- audio playback in web app
- audio download in web app
- stronger sensitive-content controls
- mobile client
- desktop client
- multi-user/public product shape

## Why this file matters

It prevents agents from:
- building future features into V1 accidentally
- treating postponed ideas as current requirements
