# Product and Problem

## Product name

Memora

## Product summary

Memora is a private, single-user capture-and-review system for thoughts.

The user sends voice or text input through a Telegram bot. The system processes the content asynchronously, produces structured output, and exposes it in a web application for review, approval, editing, search, and retrieval.

## Core problem

The user often has many thoughts, ideas, reminders, reflections, and similar mental objects in mind at once.

Typing them manually into a basic notes app is:
- slow
- tiring
- boring
- low-structure
- hard to review later

Raw notes also become a chaotic pile of text with poor retrieval value.

## Main product goal

Help the user:
- get thoughts out of the head quickly
- capture them via Telegram
- structure them automatically
- review AI output before trusting it
- retrieve approved items later through the web UI

## V1 target user

Exactly one user: the product owner.

## Main success outcomes

After one month of use, the product should help with:
- fewer ideas lost
- easier retrieval
- cleaner thinking
- more ideas turned into projects/content
- less mental overload

## Product shape

### Capture surface
Telegram bot.

### Main management/retrieval surface
Web application.

### Source of truth
Backend.

### Trust model
Review-first.
